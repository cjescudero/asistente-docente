## 2026-10-04 · Lector HTML y reorganización del grafo

Añadido `index.html` como lector de las trece páginas del ejemplo, con navegación
desde el índice, enlaces internos, búsqueda y separación del contenido reservado.

visible después de filtrar. Se mantienen fuentes, estados de lectura y relaciones.

## 2026-10-03 · Adaptación del ejemplo sintético a Mapa docente

Dos carpetas de origen seleccionadas para el ejemplo: materiales del curso y
archivo de evaluaciones. Se registran siete fuentes, cinco completas, una
parcial y una pendiente. Añadido un taller sintético, separado del resto de tipos.
Las páginas compartibles y las referencias reservadas usan carpetas distintas.
Las relaciones se expresan mediante enlaces Markdown normales.

La distribución visual se deriva del mapa y no es una nueva fuente académica.
Una consulta puntual no modifica los estados de lectura guardados.
