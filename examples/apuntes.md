# Medir y comparar

Una medición combina un valor y una unidad. Para comparar dos mediciones,
comprueba primero que representan la misma magnitud y usan unidades compatibles.

## Media de dos medidas

Si dos medidas de longitud son \(x_1=2\,\mathrm{m}\) y \(x_2=4\,\mathrm{m}\),
su media aritmética es:

\[\bar{x}=\frac{x_1+x_2}{2}=3\,\mathrm{m}\]

La media resume estas dos observaciones. No demuestra por sí sola que el
instrumento esté bien calibrado.

| Concepto | Comprobación |
| --- | --- |
| Magnitud | ¿Qué se mide? |
| Unidad | ¿Cómo se expresa el valor? |
| Tolerancia | ¿Qué intervalo se acepta? |
