# Del contenido al brief visual

## Extraer sin deformar

En Markdown y texto, aprovechar títulos, listas y relaciones. En presentaciones, leer título, notas y figuras; si se pide una única imagen, elaborar una síntesis de todo el contenido. En documentos largos, dividir por secciones lógicas. En CSV u hojas, identificar métricas, categorías y unidades, y comprobar los valores antes de elegir un mensaje. En JSON o datos estructurados, representar entidades y relaciones, no volcar el objeto entero.

El brief debe registrar: idioma, tipo de imagen, formato, idea central, título, etiquetas visibles, relaciones, patrón, elementos visuales, texto literal y hechos que deben conservarse. En modo presentación, convertir cada explicación del ponente en una palabra clave, icono, flecha o posición; no escribir su narración dentro de la imagen.

## Elegir composición

| Relación | Composición |
| --- | --- |
| Entrada, transformación y resultado | Flujo horizontal o vertical |
| Etapas sucesivas | Secuencia numerada |
| Cambio histórico | Camino, escalera o línea temporal con pocos hitos |
| Partes de un sistema | Capas o módulos conectados |
| Opciones según criterios comunes | Comparación equilibrada |
| Revisión y aprendizaje | Ciclo con flechas |
| Conceptos relacionados | Mapa con conexiones significativas |
| Clases y subclases | Árbol o jerarquía |
| Estado inicial y resultado | Antes, transformación y después |

En cualquier patrón, mantener pocos elementos grandes. Una flecha debe expresar una relación real; no introducir causalidad solo para llenar la composición.

## Briefs completos de ejemplo

**Historia, apoyo oral.** Idea: contextualizar una fuente antes de interpretarla. Título: «Leer una fuente». Tres anclas: «Autoría», «Contexto», «Propósito». Composición triangular alrededor de un documento dibujado. Relaciones: cada ancla señala el documento; ninguna implica prioridad temporal. Sin párrafos ni conclusión extra.

**Biología, apoyo oral.** Idea: una conclusión experimental depende de la comparación con un control. Título: «Comparar para explicar». Anclas: «Control», «Tratamiento», «Resultado». Dos recipientes esquemáticos y una comparación final. Conservar la condición de variables equivalentes si figura en la fuente; no inventar resultados medidos.

**Lengua, infografía autónoma.** Idea: distinguir tesis, evidencia y explicación en un párrafo argumentativo. Título: «Sostener una idea». Tres bloques conectados: «Tesis: plantea la afirmación», «Evidencia: aporta un dato o una cita», «Explicación: muestra cómo la evidencia apoya la tesis». Cierre: «La evidencia necesita interpretación». Iconos sencillos y una única dirección de lectura.
