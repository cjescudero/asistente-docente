# Construir el prompt

Redactar instrucciones de generación en inglés y declarar por separado el idioma del texto visible. Transformar el brief en un prompt completo antes de enviarlo; no dejar campos vacíos ni marcadores de plantilla en la entrega final.

El prompt debe contener: propósito, formato, tipo, composición, texto exacto, relaciones, estilo obligatorio, exclusiones y comprobaciones. Para varias imágenes, repetir las decisiones de familia visual y variar solo el contenido y la composición necesarios.

## Ejemplo completo: apoyo oral de historia

```text
Create one 16:9 didactic visual note slide. All visible text must be Spanish.
Purpose: help a teacher explain that interpreting a historical source requires
attention to authorship, context and purpose. This is support for an oral talk,
not a standalone reading handout.

Mandatory style:
Hand-drawn educational sketchnote; warm cream background; clean but slightly
irregular black ink; very soft desaturated pastel accents; large handwritten
labels; simple doodles; plenty of whitespace.

Composition:
A central hand-drawn document, with three large surrounding visual anchors.
Title at the top: "Leer una fuente".
Exact labels: "Autoría", "Contexto", "Propósito".
Connect each anchor to the document. Do not connect the anchors as a timeline.
Use a pen icon for authorship, a simple clock for context and a small target
for purpose. Use pale lavender, mint and peach, keeping the background cream.

Text requirements:
Only the title and three labels. Preserve accents exactly. Very large text
that remains legible when projected. No subtitle, explanatory sentences,
speaker notes, invented quotations or extra facts.

Strictly avoid:
Corporate infographic, institutional poster, glossy vector style, stock icons,
realistic people, dominant dark blue, saturated colors, gradients, shadows,
tiny text, dense tables and crowded boxes.
```

## Adaptación a una infografía autónoma

Cambiar explícitamente el tipo y el propósito. Incluir el texto suficiente para comprender sin ponente, con unas 35–70 palabras visibles cuando sea razonable. Mantener relaciones y jerarquía; no rellenar todos los huecos con texto. Si se exigen frases literales extensas, repartir el contenido en varias imágenes o ajustar el formato solicitado.

## Cuando falta generación de imágenes

Entregar el brief y el prompt terminado, con una frase que identifique la imagen pendiente. No llamar «infografía generada» a esa entrega. Una alternativa SVG, HTML o vectorial solo procede cuando el usuario la ha elegido.
